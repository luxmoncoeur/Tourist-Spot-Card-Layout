# 🗺️ Tourist Spot Card Layout - Lab Work

This lab work exam focuses on the **basics of React Native**, specifically exploring component structures, styling with Flexbox, and managing local assets. It demonstrates how to build a clean, functional UI using card-based layouts to display travel details and destination info.

---

### ✨ Lab Work Focus
* **React Native Fundamentals:** Understanding the core building blocks like Views, Text, and Images.
* **Layout & Styling:** Implementing a "Card Layout" using Flexbox to handle different screen sizes.
* **Asset Handling:** Managing and rendering local image assets (Amalfi Coast series).
* **Project Structure:** Organizing a React Native project for better maintainability.
